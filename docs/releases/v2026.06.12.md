# 2026.06.12 - Music Assistant 接入增强

本版本集中整理了此前测试版中围绕 Music Assistant 的 Jellyfin / OpenSubsonic 兼容性修复，并补齐 Jellyfin 入口的个人歌单、每日推荐和高品质播放体验。

从这个版本开始，Music Assistant 新接入更建议优先使用 Jellyfin。Jellyfin 入口已经覆盖用户自己的歌单、每日推荐、搜索、播放和高品质音频等主要使用场景；OpenSubsonic / Subsonic 入口仍会保留，但兼容性和使用流畅度都不如 Jellyfin，后续维护重心会逐步转向 Jellyfin。

功能更新

- Jellyfin 支持用户歌单库  
  Music Assistant 通过 Jellyfin provider 接入后，可以在歌单库中浏览当前登录账号的云音乐个人歌单。

- Jellyfin 增加每日推荐歌单  
  歌单库中会显示“每日推荐”虚拟歌单，内容来自云音乐每日推荐歌曲。该虚拟歌单使用本地保留 ID `pl_0`，避免和真实云音乐歌单 ID 冲突。

- Jellyfin 根入口拆分音乐库和歌单库  
  为 Music Assistant 提供音乐库与歌单库两个 CollectionFolder，改善媒体库同步和浏览结构。

修复

- 修复 Jellyfin 登录态缓存问题  
  当 HA 集成内登录用户变化后，Jellyfin 虚拟库和歌单库的 ETag 会随之变化，便于 Music Assistant 重新同步。

- 修复 HA 集成复用旧登录态的问题  
  `cloud_music.userinfo` 会在 storage 文件变化后重新加载，避免长时间沿用旧内存状态。

- 修复部分高品质音频在 Music Assistant 中播放失败的问题  
  播放链接增加 HA 兼容转发并支持 Range 请求，减少 FLAC 播放失败、跳歌或 ffmpeg 报错。

- 优化播放 URL 兜底策略  
  仅在主播放链路不可用或疑似试听片段时启用备用链路，避免错误传递低质量或不可完整播放的链接。

- 修复每日推荐歌单封面不显示的问题  
  每日推荐封面会使用推荐歌曲的专辑封面，并正确返回图片跳转。

- 修复部分非标准歌曲数据导致的报错  
  兼容云音乐播客主声音频等歌手列表为空的情况，避免单曲播放或详情解析时报错。

- 修复 OpenSubsonic 搜索结果中的异常播放链接  
  部分不可完整播放的链接不再被当作正常歌曲返回。

- 改善 OpenSubsonic 歌单元数据  
  减少 Music Assistant 后台 artistId 相关日志。

维护说明

- OpenSubsonic / Subsonic 入口进入低优先级维护  
  由于 Jellyfin 入口已经覆盖主要功能，并且在 Music Assistant 中的展示结构、同步行为和播放体验更接近预期，后续 Subsonic 入口将主要处理严重回归或必要兼容问题，长期重心会转向 Jellyfin。

升级说明

- 升级后建议重启 Home Assistant。
- 已经在 Music Assistant 中添加过 Jellyfin provider 的用户，升级后建议手动同步一次；如果仍显示旧结果，可以删除并重新添加 Jellyfin provider。
- Music Assistant 新接入建议优先选择 Jellyfin provider，不再建议优先使用 OpenSubsonic / Subsonic 入口。
