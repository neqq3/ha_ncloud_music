这是一个面向播放启动失败重试逻辑的测试版本，主要验证不同 Home Assistant 媒体播放器状态上报不一致时的兼容性。

### 新增

- 新增“高级设置”折叠区域，减少普通用户需要直接面对的配置项。
- 新增“禁用播放启动失败重试的设备”选项。
- 播放启动失败重试默认对所有关联播放器启用。
- 如果某些设备已经实际播放，但 Home Assistant 状态更新较慢，导致歌曲重新开始，可以在高级设置中为该设备禁用自动重试。

### 修复与优化

- 每次播放会话最多自动重试一次，避免同一播放请求无限重复从头播放。
- 播放启动确认窗口内不会触发自动重试。
- 外部 TTS 或其他播放器接管期间不会触发播放启动失败重试。
- 按底层播放器实体独立判断是否启用重试，避免一个全局开关影响所有设备。

### 注意

- 这是 beta 版本，建议先在测试环境或备用 Home Assistant 中验证。
- 如果遇到歌曲已经播放但十几秒后重新开始，请将对应设备加入“禁用播放启动失败重试的设备”。
- 如果遇到集成显示播放但设备没有声音，请不要禁用该设备的启动失败重试。

### 已验证

- `SectionConfig` 可正常导入。

- TTS 或外部播放接管期间的恢复行为。
