# 2026.04.26 - 登录二维码与 Music Assistant 接入说明

本版本修复并补充了 issue #8 中提到的两个实际使用问题：Home Assistant 媒体浏览器中的扫码登录二维码空白，以及 Music Assistant 使用 Jellyfin 接入时服务地址不明确。

## 修复

- 修复扫码登录二维码空白问题  
  二维码图片不再依赖第三方生成，改为使用登录 API 返回的 `qrimg`，并通过本集成本地路由 `/cloud_music/qrcode` 返回图片，减少外部服务不可用导致的登录失败。

## 文档

- 明确 Jellyfin 接入地址  
  README 已补充 Music Assistant 的 Jellyfin 接入参数：`Server URL` 应填写 `你的 HA 地址/jellyfin`，例如 `http://192.168.1.10:8123/jellyfin`；用户名和密码可任意填写。

## 升级说明

- 升级后建议重启 Home Assistant。
