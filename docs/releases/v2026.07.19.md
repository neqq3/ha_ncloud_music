# 2026.07.19 - 播放启动重试优化

本版本修复 [issue #12](https://github.com/neqq3/ha_ncloud_music/issues/12) 中底层播放器状态上报较慢时，播放启动失败重试可能导致歌曲重新开始的问题，并优化集成选项页结构。

## 功能更新

- 播放启动失败重试改为默认启用，并支持按底层播放器实体单独禁用。
- 选项页新增默认折叠的“高级设置”区域，集中放置切歌时机、自定义 API 地址和播放启动失败重试设置。
- 状态更新较慢、已经实际播放但仍短暂报告 `idle` 或 `off` 的设备，可以加入“禁用播放启动失败重试的设备”。

## 播放稳定性

- 每首歌曲最多自动重试一次，避免同一播放请求反复从头开始。
- 播放启动确认窗口内不会触发失败重试。
- 外部 TTS、其他播放器接管或用户手动停止期间不会触发失败重试。
- 禁用某个设备的启动失败重试后，代理播放器的进度更新和自动切歌仍会正常运行。

## 升级说明

- 升级后建议重启 Home Assistant。
- 如果音箱已经播放，但偶尔在十几秒后重新开始，请在集成高级设置中禁用该设备的播放启动失败重试。
- 如果设备偶尔完全无法开始播放，请保持该设备的启动失败重试为启用状态。
